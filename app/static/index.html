ChatGPT 订阅与账单查询

粘贴你自己的 session → 点击获取 → 在本页看真实订阅截图和账单，预览并下载原始发票 PDF。无需注册，不用账号密码。

Access token 不能替代 session cookie：它无法让浏览器登录 chatgpt.com，也打不开 Billing 和 Stripe 门户，所以无法截图、也无法下载发票 PDF。请改用 session cookie。

怎么复制：在电脑浏览器登录 chatgpt.com → F12 → Application → Cookies → chatgpt.com → 复制 __Secure-next-auth.session-token；如果它被分成 .0、.1……，请全部复制。也可以在 Network 里复制整条 Cookie 请求头。不要发到聊天里，只粘贴在这里。

隐私：session 只在本次任务的浏览器内存里用，不写入磁盘、不进日志、不进 URL；截图和发票只保存在本次任务目录，30 分钟后自动删除，不同任务用不同凭证互相隔离。本工具不购买、不取消、不修改订阅。

    如果失败了，常见原因

    1）Session 未登录 / 已过期：页面跳回登录页。请重新复制完整 session（含全部 .0/.1 分段）。
    2）浏览器人机验证：遇到 Cloudflare / Turnstile，本工具不自动解验证，请稍后重试。
    3）HTTP 403：服务端拒绝了本次访问。有效 session 不等于服务端一定放行。
    4）Apple / Google Play 订阅：发票不在 Stripe，由苹果/谷歌开具，本页会如实说明，不会凭空生成 PDF。
    5）本工具不保证一定成功；失败时会明确写出失败阶段，不会只给一个入口链接。
